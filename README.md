The funniest error message a kitchen toaster would show its owner, in 120 characters or fewer. One line, deadpan, from a toaster that keeps a quiet grudge about every slice its owner walked away from.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or to `$TOASTER_OUTPUT_DIR/entry.txt` when that is set, for local runs).
